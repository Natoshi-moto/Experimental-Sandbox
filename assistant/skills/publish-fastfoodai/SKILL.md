# Publish FastFoodAI

1. Read the relevant experiment records, receipts and operator transcript excerpts.
2. Never invent a FastFoodAI subreddit/account URL. Use `CHANNEL_URL_PENDING` until configured.
3. Produce one source report, then derive platform variants:
   - daily field note
   - weekly evidence report
   - Reddit discussion post
   - X single post or thread
   - build-video log with chapters and linked commit
4. Keep `observed`, `inference`, `opinion`, `failed`, and `next test` visibly distinct.
5. Preserve the operator’s voice without fabricating certainty or affiliations.
6. Link public experiment IDs, commits, methods and raw evidence.
7. Include model/provider disclosure for substantial AI drafting.
8. Draft by default. Publishing to external accounts requires the operator’s explicit target and approval unless a separately bounded schedule exists.

Read [references/report-formats.md](references/report-formats.md) for the canonical content shapes.
