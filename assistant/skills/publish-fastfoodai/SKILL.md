# Publish FastFoodAI

Current scoped hold: [`SBX-SOH-001`](../../../EMERGENCY_CURRENT_STATUS.md).

1. Read the root emergency status and every active hold affecting the subject.
   Publication language may not turn a held design into an approved design.
2. Read the relevant experiment records, receipts, and only those operator
   transcript excerpts explicitly authorised for publication.
3. Never invent a FastFoodAI subreddit/account URL. Use `CHANNEL_URL_PENDING`
   until configured.
4. Produce one source report, then derive platform variants:
   - daily field note
   - weekly evidence report
   - Reddit discussion post
   - X single post or thread
   - build-video log with chapters and linked commit
5. Keep `observed`, `inference`, `opinion`, `failed`, and `next test` visibly distinct.
6. Preserve the operator’s voice without fabricating certainty or affiliations.
7. Link public experiment IDs, commits, methods and raw evidence.
8. Include model/provider disclosure for substantial AI drafting.
9. Draft by default. Publishing to external accounts requires the operator’s
   explicit target and approval unless a separately bounded schedule exists.
10. For an in-scope held subject, lead with the canonical public holding
    statement and link the order.
