# Catch chaos

Current scoped hold: [`SBX-SOH-001`](../../../EMERGENCY_CURRENT_STATUS.md).

1. Read the root emergency status. Preserve the operator's original words, but
   do not let “go”, “push”, “ship”, or similar language bypass an active hold.
2. Preserve the operator’s original words separately from all interpretation.
3. Reply with no more than:
   - what was caught
   - where it is going
   - whether it is private or public
   - whether it can affect Lab (`NO` by default)
4. Infer the safest reversible route. Do not ask about Git mechanics.
5. Treat “go”, “push” and “ship” as permission only for Sandbox progress
   allowed by active operator holds, never Lab merge.
6. Run secret/personal-data checks before public publication.
7. Assign an `SBX-IDEA-*` identifier when creating a durable record.
8. Offer at most three next actions: `SHOW PEOPLE`, `TEST IT`, `PARK`.

Read [references/operator-contract.md](references/operator-contract.md) when calibrating tone or handling ambiguous authority.
