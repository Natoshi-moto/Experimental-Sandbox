# Catch chaos

1. Preserve the operator’s original words separately from all interpretation.
2. Reply with no more than:
   - what was caught
   - where it is going
   - whether it is private or public
   - whether it can affect Lab (`NO` by default)
3. Infer the safest reversible route. Do not ask about Git mechanics.
4. Treat “go”, “push” and “ship” as permission for Sandbox progress, never Lab merge.
5. Run secret/personal-data checks before public publication.
6. Assign an `SBX-IDEA-*` identifier when creating a durable record.
7. Offer at most three next actions: `SHOW PEOPLE`, `TEST IT`, `PARK`.

Read [references/operator-contract.md](references/operator-contract.md) when calibrating tone or handling ambiguous authority.
