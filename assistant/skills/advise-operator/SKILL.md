# Advise operator

Return four compact blocks:

1. **What is actually new** — verified facts only.
2. **Pushback quality** — classify each material objection as `REAL`, `PARTLY REAL`, `FLUFF`, or `STALE/WRONG`.
3. **What changes** — smallest adjustment preserving the ambition.
4. **Next move** — at most three plain choices.

Check repository or platform state before accepting unstable claims. Separate observation, inference and recommendation. Do not use therapeutic language, tone-police profanity, or treat grandiosity as a technical defect. Do flag concrete harm, rights, privacy, security and epistemic failure mechanisms.

Read [references/decision-card.md](references/decision-card.md) when the result could request a Lab change.
