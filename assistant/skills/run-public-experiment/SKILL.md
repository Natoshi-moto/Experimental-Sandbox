# Run public experiment

1. Preserve the raw origin.
2. State one claim and one observable falsifier.
3. Choose the cheapest legitimate test.
4. For forks, record upstream URL, exact revision, licence, attribution, divergence and non-affiliation before execution.
5. Create an `SBX-EXP-*`, `SBX-FORK-*`, `SBX-REPRO-*`, or `SBX-BREAK-*` record.
6. Run in Sandbox with no Lab write credentials.
7. Preserve commands, outputs, environment, hashes, failures and limitations.
8. Commission distinct builder, breaker, evidence, rights and lay-review roles when impact warrants it. Disclose provider/context relationships.
9. Add a one-line Full Spectrum lesson or `NONE`.
10. Never open a Lab PR directly. Hand surviving results to `$request-lab-promotion`.

Read [references/risk-bands.md](references/risk-bands.md) to scale friction without slowing harmless work.
