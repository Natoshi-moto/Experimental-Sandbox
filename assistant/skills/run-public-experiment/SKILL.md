# Run public experiment

Current scoped hold: [`SBX-SOH-001`](../../../EMERGENCY_CURRENT_STATUS.md).

1. Read the root emergency status. If the subject is in scope of an active
   operator hold, limit work to its expressly allowed research classes and mark
   the record accordingly. No phrase bypasses the hold.
2. Preserve the raw origin.
3. State one claim and one observable falsifier.
4. Choose the cheapest legitimate test.
5. For forks, record upstream URL, exact revision, licence, attribution,
   divergence and non-affiliation before execution.
6. Create an `SBX-EXP-*`, `SBX-FORK-*`, `SBX-REPRO-*`, or `SBX-BREAK-*` record.
7. Run in Sandbox with no Lab write credentials.
8. Preserve commands, outputs, environment, hashes, failures and limitations.
9. Commission distinct builder, breaker, evidence, rights and lay-review roles
   when impact warrants it. Disclose provider/context relationships.
10. Add a one-line Full Spectrum lesson or `NONE`.
11. Never open a Lab PR directly, and never package a held direction for Lab.
    Hand eligible surviving results to `$request-lab-promotion`.

Read [references/risk-bands.md](references/risk-bands.md) to scale friction without slowing harmless work.
