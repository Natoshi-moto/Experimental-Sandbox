# Risk bands

## Green

Text, mockups, synthetic data, isolated code, no external writes. Publish rapidly after secret check.

## Amber

Third-party code/data, public claims about identifiable parties, paid services, user interaction, networked demos. Check licences, evidence and rollback.

## Red

Credentials, personal data, production systems, financial value, security exploitation, irreversible external actions or Nexus Lab canonical state. Stop for explicit scoped authority and specialist review.

Controversy and profanity alone do not raise a risk band.
