# Assistant router

The router converts ordinary operator language into one bounded skill. It records the selected route, mode and maximum authority. It is not authentication to Nexus Lab.

## Local profile gate

The browser app asks who is entering and stores a local profile:

- **Operator** — full Sandbox drafting and publishing preparation
- **Contributor** — ideas and experiment proposals
- **Reader** — course and public records

No profile grants Lab authority. Real GitHub permissions remain the enforcement boundary.
