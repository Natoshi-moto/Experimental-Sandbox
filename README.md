# 🧪 Experimental Sandbox

> **FUCK-AROUND LAND. Public, reversible, noncanonical.**
>
> This repository cannot speak for Nexus Lab. Nothing here becomes canonical because it is exciting, popular, polished, or AI-approved.

This is the public chaos engine behind **Mithub** and **Full Spectrum University**: somewhere non-coders, researchers, builders and breakers can publish radical ideas, fork systems, run experiments, show failures, reproduce results and ask—separately—for useful findings to be considered by [Nexus Lab](https://github.com/Natoshi-moto/Lab).

## You do not need to code

Use one of these doors:

- 🤖 **ADJACENT** — [open the assistant source](assistant/app/) or run its local browser prototype
- 🧠 **DRIBBLE** — [post a raw idea](https://github.com/Natoshi-moto/Experimental-Sandbox/discussions/categories/ideas)
- 🧪 **TEST IT** — [propose the smallest experiment](../../issues/new?template=experiment.yml)
- 🍴 **FORK IT** — [open a fork-research record](../../issues/new?template=fork-research.yml)
- 🧨 **BREAK IT** — [request adversarial review](https://github.com/Natoshi-moto/Experimental-Sandbox/discussions/categories/show-and-tell)
- ✍️ **TEACH IT** — [turn the wreckage into a Full Spectrum lesson](course/README.md)
- 🚨 **ASK LAB** — [prepare a promotion package](templates/PROMOTION.md)

Say what you mean in ordinary language. Boring agents handle branches, commits, checks, receipts and packaging.

Fresh AI session? Say only:

> **Let’s fuck around in the sandbox.**

The provider-neutral contract is in [`HANDOFF_ANY_AI.md`](HANDOFF_ANY_AI.md).

## The only three inherited rules

1. `status_authority: NONE` unless Nexus Lab explicitly adopts something.
2. Never publish secrets, private keys or personal data you do not have the right to publish.
3. Sandbox records use `SBX-*` identifiers. They never impersonate Lab claim, task or decision IDs.

Everything else may be ugly, abandoned, offensive to convention, disproven or rebuilt.

## What “public” means

Assume commits, discussions, issues, comments, datasets and previews may be copied, indexed and preserved. Draft locally when material is sensitive. Public research is not a magic copyright, privacy, trademark, patent or harassment exemption.

## Promotion is a request, not a tunnel

An experiment may request consideration by Lab only through a promotion package containing:

1. immutable Sandbox origin
2. falsifiable claim
3. falsifier
4. reproducible evidence—or `DOCUMENTARY_ONLY`
5. explicit non-claims
6. reviewer/model relationships
7. Lab red impact—or `NONE`

Lab then applies its own CI, adversarial review and Human Gate. Sandbox never merges into Lab automatically.

## Full Spectrum University

Using this repository is the course:

