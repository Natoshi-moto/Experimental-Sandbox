# Mithub

Mithub is the humane gateway into this repository:

```text
DRIBBLE → SHOW PEOPLE → FORK/TEST → BREAK → TEACH → PACKAGE → ASK LAB
```

It hides Git mechanics without hiding provenance. Original human words remain distinct from agent interpretations. Dashboards and summaries are routes; repository records outrank them.

The first browser prototype lives in the Full Spectrum proposal on [`Natoshi-moto/Lab` PR #101](https://github.com/Natoshi-moto/Lab/pull/101). This repository becomes its public discussion, experiment and evidence substrate.

The first personal operating layer is [`assistant/app/`](../assistant/app/): a local-profile router that selects bounded skills, logs its route and never holds Lab credentials.

## Mithub v0 contract

- A non-coder contributes through one form or discussion.
- A custodian creates branches, IDs, receipts and checks.
- Public experimentation never grants access to Nexus Lab.
- Promotion creates a package, not an automatic merge.
- Every AI reviewer discloses model/provider metadata and context limits.
- Every experiment can become course material; no experiment is forced to become polished teaching content first.
