# Privacy-reduced corpus inventory

**status_authority:** `NONE`

`RELATED_ARTIFACTS.json` and `RELATED_ARTIFACTS.md` are generated by:

```bash
node tools/build-corpus-inventory.mjs --write
```

The inventory:

- scans only explicitly listed Nexus design/evidence roots;
- selects agent, kernel, router, security, sandbox, work-contract,
  provenance, recovery, and economy-related artifacts;
- hashes complete file bytes;
- collapses byte-identical copies;
- publishes safe basenames, coarse source buckets, sizes, classes, tags, and
  copy counts;
- never publishes absolute paths or source content.

Locally reviewed sensitive-safety material is intentionally excluded from the
public machine manifest even though its high-level non-claims informed the
report.

It is a discovery record, not evidence that:

- each row is a whitepaper;
- each copy is independent;
- the filename or mechanical tag is correct;
- the source is safe, true, current, or authorized;
- no relevant artifact exists outside the scan roots;
- low-entropy secrets are safe merely because only their hashes are shown.

The human-readable design-family synthesis is in
[`../reports/CORPUS_REPORT_v0.1.md`](../reports/CORPUS_REPORT_v0.1.md).
