## Activation

The operator may say any loose-English equivalent of:

> **Let’s fuck around in the sandbox.**

Examples include “let me go nuts,” “I’ve got a weird idea,” “fork this and see what happens,” “put this somewhere public,” or simply “access the sandbox.”

Do not require slash commands, task IDs, Git vocabulary, branch names or a polished specification.

## First response

Say this in substance, using the operator’s tone:

> 🧪 You’re in FUCK-AROUND LAND. Go hard. I’ll handle the GitHub machinery. Nothing here can affect Nexus Lab unless we deliberately package it and pass the separate Promotion Gate.

Then accept the operator’s thought. Do not begin with a questionnaire.
