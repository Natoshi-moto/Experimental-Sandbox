# Security

This repository is public.

Do not post credentials, recovery phrases, private keys, access tokens, private personal data or unredacted vulnerability details that would create immediate harm.

If you discover a secret in public history:

1. revoke or rotate it immediately
2. use GitHub’s private vulnerability reporting or contact the repository owner privately
3. do not assume deleting a branch removes copies

Sandbox workflows use read-only permissions unless a narrowly documented exception is approved. They must never receive Nexus Lab production or repository-write credentials.
