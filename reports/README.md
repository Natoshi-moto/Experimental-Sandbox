# Public reporting

FastFoodAI reporting is generated from experiment evidence, not memory alone.

| Folder | Cadence/output |
|---|---|
| `daily/` | compact field notes |
| `weekly/` | claims, evidence, failures and next tests |
| `reddit/` | discussion-first Reddit drafts |
| `x/` | single posts and threads |
| `video/` | build logs, chapters, commits and corrections |

Exact FastFoodAI Reddit/X URLs remain `CHANNEL_URL_PENDING` until the operator supplies or publicly verifies them.
